Політика конфіденційності WTD SPORT CLUB

Дата набрання чинності: 24 вересня 2026 року

Ця Політика конфіденційності описує, як ГО «СПОРТИВНИЙ КЛУБ «В.Т.Д СПОРТ КЛУБ» обробляє персональні дані користувачів мобільного застосунку WTD SPORT CLUB.

1. Які дані ми можемо обробляти

Для роботи застосунку можуть оброблятися:

  • номер телефону, який використовується для авторизації;
  • ідентифікатор клієнта та дані облікового запису;
  • інформація, необхідна для роботи профілю користувача;
  • інформація про тренування та записи на тренування;
  • спортивні результати, досягнення та інші дані, пов'язані з функціоналом клубу;
  • дані, необхідні для роботи сесії авторизації та безпеки сервісу.

2. Для чого використовуються дані

Дані використовуються для:

  • авторизації користувача в застосунку;
  • надсилання одноразового коду підтвердження;
  • відображення розкладу тренувань;
  • запису та керування заявками на тренування;
  • відображення особистого прогресу та спортивних результатів;
  • роботи системи досягнень та WTD POINTS;
  • забезпечення стабільної та безпечної роботи застосунку.

3. Авторизація через номер телефону

Для входу в застосунок використовується номер телефону. Після введення номера телефону користувач отримує одноразовий код підтвердження через SMS.

Одноразовий код використовується виключно для підтвердження авторизації. Постійний пароль для входу в застосунок не використовується.

4. Передача даних третім сторонам

Ми не продаємо та не передаємо персональні дані користувачів третім сторонам для їх власних маркетингових цілей.

Для забезпечення роботи окремих функцій застосунку можуть використовуватися сторонні технологічні сервіси та постачальники, які обробляють дані виключно в межах необхідного для надання відповідних послуг.

Для надсилання SMS-повідомлень використовується сервіс TurboSMS.

5. Захист інформації

Ми застосовуємо технічні та організаційні заходи для захисту інформації від несанкціонованого доступу, зміни, втрати або неправомірного використання.

Одноразові коди авторизації не зберігаються у відкритому вигляді.

6. Зберігання даних

Дані зберігаються протягом періоду, необхідного для забезпечення роботи облікового запису, функцій застосунку та виконання відповідних організаційних і законодавчих вимог.

7. Права користувача

Користувач може звернутися до адміністрації WTD SPORT CLUB щодо доступу до своїх персональних даних, їх виправлення або видалення, якщо це можливо відповідно до законодавства та особливостей роботи сервісу.

8. Дані неповнолітніх користувачів

Застосунок WTD SPORT CLUB може використовуватися спортсменами неповнолітнього віку. У відповідних випадках робота з даними неповнолітніх здійснюється за участю їхніх батьків або законних представників.

9. Зміни до Політики конфіденційності

Ми можемо періодично оновлювати цю Політику конфіденційності. Оновлена версія публікується на цій сторінці із зазначенням відповідної дати набрання чинності.
